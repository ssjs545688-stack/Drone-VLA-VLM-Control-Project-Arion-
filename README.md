 🚁 Drone-VLA-VLM-Control-Project-Arion

비전 언어 행동 모델(VLA/VLM)을 활용한 드론 자율 제어 및 비행 시스템 프로젝트입니다. 로컬 환경에서 구동 가능한 소형 LLM(Qwen)을 기반으로, 드론의 인지 및 제어 파이프라인을 최적화하는 것을 목표로 합니다.

## 📅 프로젝트 개발 일지 (진행 상황)

### [2026.09.14] 작업 환경 구성 및 기초 교육
- **환경 셋업**: Ubuntu OS 기반 작업 환경 구축
- **필수 소프트웨어 설치**: PX4 Autopilot, QGroundControl 등 프로젝트 필수 도구 설치 완료
- **이론 교육**: 드론 제어 및 비행 기초 이론 교육 진행

### [2026.09.15] 모델 선정 및 시스템 분석
- **AI 모델 확정**: `Qwen3-0.6B` 텍스트 모델과 `OpenCV` 비전 기술 혼합 적용
  - *Note*: 향후 음성 인식 도입을 위해 `Qwen-ARS 3-0.6`으로의 업그레이드 확장성 고려
- **시스템 분석**: PX4 기반 제어 시스템 아키텍처 분석
- **설계 논의**: 모델에 입력할 함수 스키마(Function Schema)의 정의 및 데이터 포맷팅 방식 논의

### [2026.09.16] 스키마 구조 확정 및 모델 파인튜닝
- **데이터셋 구축**: 확정된 스키마를 기반으로 파인튜닝용 데이터셋 제작
- **스키마 포맷 전환**: 이전 기수의 Gemini용 자연어 프롬프트 방식을 탈피하여, 소형 모델(Qwen)의 처리 부담을 줄이기 위한 **JSON 형식의 맞춤 스키마**로 개편 (향후 JSON 스키마 별도 분리 예정)
- **코드 모듈화**: 원활한 유지보수와 수정을 위해 코드 구조 분할
- **모델 학습 진행 중**: 제작된 데이터셋을 바탕으로 Qwen 모델 파인튜닝(학습) 시작
  - *이슈*: 클라우드 환경 내 타 사용자 작업으로 인한 장애 발생, 세션 종료 및 긴 학습 시간으로 인해 결과 확인은 익일(9.17)로 연기
